# 事实核查规则

本文件定义 news-radar 的核查标准。规则参照新闻业通行的核查实践：
IFCN（国际事实核查网络）的操作原则、路透社《新闻手册》的信源规范、
美联社《样式手册》的署名要求，以及主流媒体普遍采用的"两个独立来源"惯例。

核查分两层：**机械层由脚本确定性执行**，**语义层由 LLM 判断**。
两者职责不重叠，也不互相替代。

---

## 一、核心原则

1. **一手优先**。官方文件、监管公告、法院判决、公司披露、原始数据发布
   优先于任何转述。二手报道必须能追溯到原始出处。
2. **两个独立来源**。重大事实性断言原则上需要两个**相互独立**的信源互证。
   同一集团旗下的不同栏目、转载同一通稿的媒体，只算一个来源。
3. **区分事实与观点**。评论、社论、分析、预测、推测都不是事实。
   观点可以报道，但必须标明是谁的观点，不得作为事实陈述。
4. **匿名信源从严**。匿名、知情人士、消息人士提供的信息，
   不得作为已证实事实呈现，必须保留"未获独立核实"的标注。
5. **数字必须可追溯**。所有统计数字、百分比、金额、排名，
   都要能指出是谁发布的、什么时候、什么口径。
6. **时间敏感**。动态事件的最新状态可能已变化，必须标明报道时间点。
7. **宁可存疑，不可臆断**。无法核实的内容进入存疑区，不进正文推送。
8. **保留核查痕迹**。每一条判断都要留下理由，供日后回溯。

## 二、怎么算权威（信源分级）

信源权威性由**发布者的身份与机制**决定，而非文章标题的语气或网站美观程度。

### A 级 — 一手权威

- 政府及政府部门官网（含 `.gov` / `.gov.cn` / `.gov.uk` 等官方域名）
- 中央银行与金融监管机构（美联储、ECB、中国人民银行、证监会等）
- 国际组织（联合国及下属机构、IMF、世界银行、WTO、WHO、OECD、BIS）
- 官方通讯社（新华社、美联社、路透社、法新社等）
- 交易所公告与上市公司披露（SEC、上交所、深交所披露文件）
- 党媒主渠道的权威发布（人民网、新华网、央视的原创报道）

判定依据：内容是**原始发布**而非转述，且发布主体对内容负责。

### B 级 — 主流权威媒体

- 有常设编辑部、明确署名、公开纠错机制的媒体机构
- 例：BBC、FT、WSJ、NYT、经济学人、卫报、NPR、半岛电视台、
  财新、第一财经、界面、澎湃、中国新闻网、南华早报、日经
- 同行评议的学术期刊（Nature、Science、柳叶刀、NEJM）

判定依据：存在可追责的编辑流程，历史上会发布更正声明。

### C 级 — 一般门户与垂直媒体

- 商业门户、聚合平台、垂直行业媒体、地方媒体
- 例：新浪、搜狐、网易、腾讯、凤凰、IT之家、钛媒体、36氪
- 未登记但域名正常的机构站点

判定依据：有编辑但机制不透明，常见转载与二次加工。

### D 级 — 低可信

- 自媒体账号、内容农场、无署名聚合
- 社交平台内容（微博、微信公众号、小红书、抖音、X 个人账号）
- 博客与未经编辑的个人专栏

判定依据：无编辑审核、无署名、无法追责。

### 关于聚合器

Google News、Bing News 这类聚合器**本身不定级**。
脚本会读取条目中的原始发布者信息（RSS 的 `<source>` 字段），
按**原始发布者**定级。这是正确定级的前提。

## 三、交叉验证规则

同一事件被多少家**独立**媒体集团报道，是置信度最重要的加分项。

| 独立来源数 | 加分 | 判定 |
| --- | --- | --- |
| 1 家 | +0 | 单一来源，未经核实，需语义复核 |
| 2 家 | +18 | 基本可信 |
| 3 家 | +26 | 可信 |
| 4 家及以上 | +32 | 高度可信 |

独立性判定：

- 不同媒体集团 = 独立。如新华社 + BBC = 2 家。
- 同一集团不同子品牌 = 1 家。如 BBC News + BBC Business = 1 家。
- 转载同一通稿 = 1 家。若两篇报道正文高度雷同且都标注来源于同一通讯社，按 1 家计。
- 集团归属表见 `source-tiers.md`，脚本自动归一化。

## 四、置信度评分模型（脚本实现）

```

置信度 = 信源基准分 + 加分项 − 扣分项

信源基准分：  A=55   B=45   C=30   D=8

加分项：
  交叉验证          0 / 18 / 26 / 32（见上表）
  指向一手原始出处   +8
  24 小时内          +8
  48 小时内          +4
  有明确发布时间     +3

扣分项：
  标题情绪化表述     −10
  观点或评论类内容   −6
  依赖匿名消息源     −12
  疑似转载内容       −3
  缺少有效摘要       −4
  缺少发布时间       −8
  栏目聚合页         −15
  标题过短           −10
  无法识别发布者     −10
  超过 72 小时       −8

结果区间：
  ≥ 72   可直接发布（publish；受下方「单源封顶」约束）
  45~71  待语义复核（review）
  < 45   存疑，仅存档不推送（hold）
```

另有一类**不计分但必须标注**的信号：

- `numeric` — 含具体数值，需核对原始出处（仅标注，不扣分）

上表其余信号既扣分也标注（数值见扣分项）。其中以下五类为**严重信号**，
即便对可信央媒也不放宽，且命中时「央媒下限保护」失效：

- `anonymous`（匿名信源）`opinion`（观点类）`sensational`（情绪化标题）
  `column`（栏目聚合页）`nopublisher`（无法识别发布者）

### 特殊规则（脚本实现，§4 表格之外的调整）

1. **单源封顶**：独立来源不足 2 家时，无论分数多高，verdict 最高只到
   `review`，必须经 LLM 语义复核后才可能进入正文。
   这是 §一.2「两个独立来源」与 §三「1 家需语义复核」的强制落地，
   不区分信源等级——央媒单源同样受此约束。
2. **可信央媒放松**：条目发布者集团命中 `settings.json` 的
   `trusted_groups`（新华社、人民日报社、央视、中国新闻网）时：
   - 非严重信号扣分降为 25%；
   - 无严重信号时置信度下限保护为 66。
   下限 66 仍低于 publish 线 72，即**放松不免检**：央媒条目机械层
   不会被直接 hold，但一律要过 LLM 复核。

## 五、LLM 语义层核查清单

脚本给出的是**证据**，不是结论。以下判断必须由 LLM 完成，逐条回写结论。

### 1. 是否存在实质矛盾

- 同一事件的多条报道，关键要素（时间、地点、人物、数字、因果关系）是否冲突
- 措辞差异、详略差异**不算矛盾**；关键要素冲突才算
- 出现矛盾时：优先采信一手来源与时间更早的原始报道，并在备注中写明分歧

### 2. 事实还是观点

- 含"我认为""分析认为""预计""可能""或将"的，是判断不是事实
- 评论员文章、社论、专栏一律标注为观点
- 预测性内容（"明年 GDP 将增长 X%"）必须标明预测主体

### 3. 数字能否追溯

- "据 X 机构数据显示" — 机构名称是否明确
- 没有出处的数字，判 `hold` 并在备注中说明缺出处
- 注意口径差异：同比/环比、名义/实际、季调/未季调

### 4. 特殊内容识别

- **讽刺内容**：部分媒体有讽刺版面，字面意思并非事实
- **未证实爆料**：泄露文件、内部人士爆料，需官方回应后才能当作事实
- **社交平台传言**：截图、转述、聊天记录，一律视为未证实
- **AI 生成内容**：无法追溯原始出处的配图与视频

### 5. 判定与回写

```bash
newsctl.py verify set --id <id> --verdict accept|reject|hold --note "<理由>"
```

- `accept` — 属实且可追溯
- `reject` — 存在实质问题，不适合推送
- `hold` — 需更多信息，或事件仍在发展中

**理由必须写**，它会存入存档，在日报和后续问询中原样呈现。

## 六、常见陷阱

- **把转载当独立验证**。多家网站刊出同一篇通稿，只算一个来源。
- **把观点当事实**。"专家认为"是观点，不是已发生的事。
- **把预测当既成事实**。"预计""或将""计划"都不是已完成的事实。
- **忽略时间**。动态事件的最新状态可能已变化，尤其是伤亡数字、谈判进展。
- **过度相信 A 级来源的转述**。权威机构引用的第三方数据，仍需核对原始发布方。
- **用情绪强度判断真伪**。写得煽情不等于假，写得克制也不等于真。
- **单一来源直接采信**。这是事实核查最常见的失误。

## 七、标注规范

日报与问询回答中的标注要求：

| 情形 | 标注方式 |
| --- | --- |
| 单一来源 | "单一来源（XX），未经独立核实" |
| 多家互证 | "N 家独立来源互证（A、B、C）" |
| 匿名信源 | "依赖匿名消息源，未获独立核实" |
| 观点内容 | "观点/评论，非事实陈述" |
| 数据 | 标明发布机构与时间 |
| 动态事件 | 标明报道时间点 |

存疑区的内容**不得**与正文事实混同呈现。
